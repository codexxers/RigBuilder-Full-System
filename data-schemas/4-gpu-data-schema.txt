================================================================================
  RIGBUILDER APP - GPU / GRAPHICS CARD DATA SCHEMA
  Table name in database: gpus
  Fill in one row per GPU model. Share this file with your groupmate
  responsible for GPU data entry.
================================================================================

FIELD REFERENCE
---------------

| Field Name            | Type    | Required | Description / Notes                             |
|-----------------------|---------|----------|-------------------------------------------------|
| id                    | Integer | YES      | Unique number. Start from 1, increment by 1.    |
| name                  | Text    | YES      | Full product name. e.g. "RTX 4070 Super"        |
| brand                 | Text    | YES      | e.g. "NVIDIA" or "AMD"                          |
| vramGb                | Integer | YES      | VRAM in gigabytes. e.g. 12                      |
| lengthMm              | Integer | YES      | Card length in millimeters. e.g. 336            |
| thicknessSlots        | Decimal | YES      | Slot thickness. e.g. 2.5 for a 2.5-slot card    |
| recommendedPsuWatts   | Integer | YES      | Minimum recommended PSU wattage. e.g. 650       |
| tdp                   | Integer | YES      | Power draw in Watts. e.g. 220                   |
| price                 | Decimal | YES      | Price in PHP. e.g. 29999.00                     |
| imageUrls             | List    | NO       | Comma-separated image URLs. Can leave blank.    |
| gamingTier            | Integer | YES      | Gaming tier 1–10 scale. 1=lowest, 10=highest. e.g. 8 |

--------------------------------------------------------------------------------
NOTES
--------------------------------------------------------------------------------
- thicknessSlots: Most modern cards are 2.5 or 3.0 slots. Single-fan budget
  cards may be 1.5 or 2.0. This is used for case compatibility checks.
- lengthMm: Critical for case clearance. Look this up on the manufacturer spec
  sheet or Newegg/PCPartPicker.
- recommendedPsuWatts: This is the TOTAL system wattage the GPU vendor suggests
  (not just GPU TDP). e.g., RTX 4090 suggests 850W system PSU.
- gamingTier: Use this rough guide:
    1-2  = Very old / entry level (e.g. GT 1030)
    3-4  = Budget (e.g. RX 6600, GTX 1660)
    5-6  = Mid-range (e.g. RTX 4060 Ti, RX 7700 XT)
    7-8  = High-end (e.g. RTX 4070 Super, RX 7900 GRE)
    9-10 = Flagship (e.g. RTX 4090, RX 7900 XTX)

--------------------------------------------------------------------------------
