================================================================================
  RIGBUILDER APP - CASE FAN DATA SCHEMA
  Table name in database: fans
  Fill in one row per fan model/pack. Share this file with your groupmate
  responsible for case fan data entry.
================================================================================

FIELD REFERENCE
---------------

| Field Name    | Type    | Required | Description / Notes                                      |
|---------------|---------|----------|----------------------------------------------------------|
| id            | Integer | YES      | Unique number. Start from 1, increment by 1.             |
| name          | Text    | YES      | Full product name. e.g. "Lian Li Uni Fan SL120 3-Pack"   |
| brand         | Text    | YES      | e.g. "Lian Li", "Noctua", "be quiet!", "ARCTIC", "Corsair" |
| sizeMm        | Integer | YES      | Fan diameter in mm. Either 120 or 140                    |
| quantity      | Integer | YES      | Number of fans in the pack. e.g. 1, 3                    |
| airflowCfm    | Decimal | YES      | Airflow rating in CFM (cubic feet per minute). e.g. 56.5 |
| noiseLevelDba | Decimal | YES      | Noise level in dB(A). e.g. 25.2                          |
| rgbType       | Text    | NO       | RGB type. See VALID VALUES below. Leave blank if none.   |
| price         | Decimal | YES      | Price in PHP for the full pack. e.g. 2999.00             |
| imageUrls     | List    | NO       | Comma-separated image URLs. Can leave blank.             |

--------------------------------------------------------------------------------
VALID VALUES FOR OPTIONAL FIELDS
--------------------------------------------------------------------------------

rgbType (enter exactly as shown, or leave blank):
  (blank)   → No RGB lighting
  "RGB"     → Standard RGB (4-pin)
  "ARGB"    → Addressable RGB / A-RGB (5V 3-pin)

sizeMm:
  120   → 120mm fans (most common)
  140   → 140mm fans (quieter / higher airflow)

--------------------------------------------------------------------------------
NOTES
--------------------------------------------------------------------------------
- quantity: Enter how many fans come in the box.
    e.g. if it's a single fan, enter 1. If it's a 3-pack, enter 3.
- price: This is the price for the WHOLE PACK (not per fan).
- airflowCfm: Higher = moves more air. Find on official spec sheet or product page.
- noiseLevelDba: Lower = quieter. Anything below 25 dB is considered quiet.
    Find on official spec sheet or product page.
