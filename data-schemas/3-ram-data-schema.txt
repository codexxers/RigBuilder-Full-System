================================================================================
  RIGBUILDER APP - RAM / MEMORY DATA SCHEMA
  Table name in database: rams
  Fill in one row per RAM kit model. Share this file with your groupmate
  responsible for RAM data entry.
================================================================================

FIELD REFERENCE
---------------

| Field Name       | Type    | Required | Description / Notes                                   |
|------------------|---------|----------|-------------------------------------------------------|
| id               | Integer | YES      | Unique number. Start from 1, increment by 1.          |
| name             | Text    | YES      | Full product name. e.g. "Corsair Vengeance DDR5-6000" |
| brand            | Text    | YES      | e.g. "Corsair", "G.Skill", "Kingston", "TeamGroup"    |
| generation       | Enum    | YES      | See VALID VALUES below                                |
| capacityGb       | Integer | YES      | Total kit capacity in GB. e.g. 16 for a 2x8GB kit     |
| speedMhz         | Integer | YES      | RAM speed in MHz. e.g. 6000                           |
| latency          | Text    | YES      | CAS latency string. e.g. "CL30", "CL16"               |
| modules          | Integer | YES      | Number of sticks in the kit. e.g. 2 for dual-channel   |
| colorVariants    | List    | YES      | Comma-separated available colors. e.g. "Black,White"  |
| price            | Decimal | YES      | Price in PHP for the full kit. e.g. 5499.00           |
| imageUrls        | List    | NO       | Comma-separated image URLs. Can leave blank.          |

--------------------------------------------------------------------------------
VALID VALUES FOR ENUM FIELDS
--------------------------------------------------------------------------------

generation:
  DDR4   → DDR4 standard memory
  DDR5   → DDR5 standard memory

--------------------------------------------------------------------------------
NOTES
--------------------------------------------------------------------------------
- capacityGb: Enter the TOTAL kit size.
    e.g. a "2x8GB" kit = 16, a "2x16GB" kit = 32
- modules: Usually 1 (single stick) or 2 (dual channel kit). 4 for quad-channel.
- colorVariants: List all color options the manufacturer offers for this model.
    e.g. "Black,White" or just "Black" if only one color exists.
- speedMhz: Use the advertised XMP/EXPO speed (not base JEDEC speed).
    e.g. DDR5-6000 kit → enter 6000

--------------------------------------------------------------------------------
EXAMPLE ENTRY
--------------------------------------------------------------------------------

id            : 1
name          : G.Skill Trident Z5 RGB DDR5-6000
brand         : G.Skill
generation    : DDR5
capacityGb    : 32
speedMhz      : 6000
latency       : CL30
modules       : 2
colorVariants : Black,White,Silver
price         : 8499.00
imageUrls     : (leave blank or add URL)
